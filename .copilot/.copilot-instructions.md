# Áureo - instrucciones de contexto

## Principios

- Mantener ESM (`"type": "module"`) y JavaScript moderno con JSDoc; no introducir CommonJS.
- Tratar claves privadas, tokens y URLs sensibles como secretos: nunca incluirlos en el código ni en commits.
- Validar entradas externas, registrar errores con contexto útil y no ocultar excepciones.
- Preferir cambios pequeños, testeables y compatibles con Linux/Arch Linux.

## Blockchain

- Usar OpenZeppelin para control de acceso y pausabilidad.
- Las acciones administrativas deben emitir eventos y estar protegidas por roles.
- Los despliegues deben usar Hardhat Ignition y las redes locales deben apuntar a `127.0.0.1:8545`.

## Backend

- Mantener la ingestión WebSocket separada del análisis y de la persistencia.
- El modelo xAI debe invocarse mediante el SDK oficial de OpenAI con `baseURL`.
- Validar siempre la salida del modelo antes de usarla; el JSON no es confiable por defecto.

## CLI y documentación

- Los comandos deben tener ayuda clara, códigos de salida útiles y cierre limpio de conexiones.
- Documentar decisiones arquitectónicas y cambios de contrato en `md/`.
- Ejecutar lint, formato y pruebas focalizadas antes de entregar cambios.
